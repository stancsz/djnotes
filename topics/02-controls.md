# 认识控制器

## 目标

叫得出 FLX4 上每个旋钮/按钮的名字和大致作用。这是地基课——后面每一课都会指着某个具体控件讲操作，这一步跳过，后面全会卡壳。

## 面板速览（从上到下、从左到右）

- **顶部**：Browse 旋钮（选歌、翻文件夹用，按下去=进入/确认）、Load 按钮（把选中的歌载入对应 Deck）
- **每个 Channel（左右各一条）**：
  - Trim/Gain 旋钮（进入台面前先调好电平）
  - 三段 EQ：HI / MID / LOW（各自可以旋到底把该频段完全切掉）
  - Filter 旋钮（连续扫频的高通/低通滤镜）
  - Channel Fader（推子，控制这一路进主输出的音量）
- **中间区域**：
  - Crossfader（横向推子，控制左右两个 Channel 的混合比例）
  - Beat FX 区（Echo/Delay/Reverb 等节奏同步效果）
  - Smart CFX 旋钮（FLX4 特色，单旋钮组合效果）
  - Master/Booth 音量旋钮
- **每个 Deck（左右各一套）**：
  - Jog Wheel（转盘，手动对拍/scratch 用，边缘可调 vinyl/brake 手感）
  - Tempo Fader（速度条，调整 BPM）
  - Play/Cue 按钮
  - Sync 按钮（先不用，第 5 课会详细讲为什么）
  - Loop In / Loop Out / Reloop
- **Performance Pads**：每个 Deck 4×2=8 个 Pad，可切换模式：Hot Cue / Pad FX / Beat Jump / Beat Loop / Sampler / Keyboard
- **麦克风与耳机**：Mic 输入 + Mic Level 旋钮（前面板），耳机口 + Headphone Mix/Level 旋钮

## 练习作业

不看任何资料/贴纸，自己口述 FLX4 面板上每一个旋钮和按钮的作用。说不出来的记下来，回头对着手册或视频查清楚，直到能全部说对为止。
