# Loop 与 Hot Cue

## Loop

- **手动**：LOOP IN 设起点，LOOP OUT 设终点，片段循环。
- **自动**：Beat Loop 1/2/4/8/16 小节一键循环。
- **Reloop/Exit**：跳出当前 loop / 跳回上次的 loop。

用途：延长没有明显结尾的 intro/outro 争取操作时间；卡鼓点段落做 build；现场救场——歌快完下一首还没好，loop 住垫时间。

## Hot Cue

一按 Pad 立刻跳到存好的位置。用来标记 phrase 边界、drop、干净的人声入点。第 6 课数出来的结构边界，都该固化成 Hot Cue。

## Slip Mode

开启后做 loop/跳 cue/搓盘时，歌曲在"背后"按原节奏继续走；松手后无缝回到"本来该在的位置"。花式操作不打乱歌曲进度的保险绳。

<div class="protip" markdown="1">

- **备歌做 cue 是 80% 的功力，现场只是执行。** 职业 DJ 的每首歌上场前都打好了统一规则的 cue 点。定一套自己的颜色/位置规范并且永不改变，比如：**Pad 1=混入点、Pad 2=bass 进、Pad 3=drop、Pad 4=混出点**。规则统一后，任何一首歌拿上来，你闭着眼都知道 Pad 3 是 drop。
- **Beat Jump 是最被低估的救场键。** 过渡做到一半发现 B 的操作面不够了？Beat Jump 往回跳 16/32 小节，无缝续命，观众毫无察觉。同理，A 的 outro 太长太无聊，往前跳 16 小节提前进入交接。老师傅的"从容"一半来自这个按钮。
- **Loop 长度的口诀：越短越紧张，越长越自然。** 4 拍 loop 听起来是"效果"，16/32 拍 loop 听起来是"歌本来就这样"。垫时间用长 loop，做 build-up 才用短 loop 逐级减半（4→2→1→1/2）制造压迫感——减半的时机掐 phrase 边界。
- **Hot Cue 当乐器玩（cue juggling）。** 在 drop 的第一拍打个 cue，跟着节奏反复戳，就是即兴 remix 的雏形。配合 Slip Mode 玩，砸错了歌也不会乱。这是 pad 上最有表演感的技巧，也是练节奏感的好玩具。
- **进出 loop 都掐边界。** 进 loop 的位置错了，loop 里的每一圈都是错的；出 loop 不在 phrase 边界，等于把前面数的拍全浪费了。Loop 是 phrasing 的工具，不是逃避 phrasing 的工具。

</div>

## 实操练习

1. 给 5 首常用歌按自己的 Pad 规范打满 4 个 Hot Cue。
2. 在 outro 上设 16 拍 loop 垫时间，练习从 loop 里干净地混出到下一首。
3. 做一次 build-up：8→4→2→1 拍逐级减半，掐着乐句边界收进 drop。
4. 开 Slip Mode 玩 30 秒 cue juggling，感受"底层进度"不乱。
