# 进阶 Transition 套路

在第 7 课的基础 EQ 过渡之上堆更多"招式"，让过渡有记忆点。这些套路全部建立在基本功之上——对拍、phrasing、EQ 交接还不稳的，先回去补。

## 常见套路

- **Bass Swap（快速低频交接）**：低频交接的进阶版，配合 Filter 在 1-2 小节内利落完成，适合节奏紧凑的 set。
- **Echo Out**：A 结束前挂 Echo 再猛切音量，回声拖尾盖过换歌瞬间（细节回看第 9 课干货）。
- **Hot Cue 卡 Vocal**：预先在 A 的干净人声句上打 cue，混音时精准跳进跳出，叠在 B 的伴奏上。
- **Filter Sweep + Drop**：B 的 drop 前用 Filter 从闭到开累积张力，drop 瞬间全开。
- **Double Drop**：两首歌的 drop 精确对齐同时落地。效果最炸，对精度要求也最高。

## 跨 BPM / 跨流派过渡（进阶中的进阶）

BPM 差距大（比如 house 124 → hip-hop 95）没法直接叠混，老师傅的三种解法：

1. **Echo 切**：A 乐句结尾 echo out 完全收掉，B 以自己的速度干进——不叠拍，靠收得干净。
2. **Dead stop / Spinback**：A 直接急停或倒盘刹车，制造一个戏剧性的"断"，B 顺势进。一晚上最多用一两次，多了就廉价。
3. **渐变桥**：A 尾段设 loop，趁 loop 期间把 Tempo 慢慢拉向 B 的速度（每次 1-2%，观众几乎无感），到位后正常叠混。最费功夫，也最丝滑。

<div class="protip" markdown="1">

- **一小时的 set，两三个"名场面"就够了。** 进阶技巧是调味料不是主食——老师傅的 set 骨架永远是干净的 EQ 过渡，套路只在能量需要爆点的位置出现。招式密度和专业度成反比。
- **Double Drop 的成败在 8 小节前。** 两个 drop 要同时落地，意味着两首歌的 build 必须提前 8-16 小节就对齐 phrase。倒推：先找 B 的 drop 减去 A 剩余小节数，算出 B 该从哪一拍进——这是数学题，不是手感题，在家算好打成 cue。
- **人声叠人声 = 车祸现场。** 卡 vocal 时确保 B 处在纯伴奏段（intro/breakdown）。两个人同时唱不同的歌，观众只听到"吵"。Instrumental 段落是人声套路的唯一舞台。
- **Spinback 之后接什么，比 spinback 本身重要。** 刹车产生的静默是全场注意力最高的一秒，接进来的 B 必须是硬货（直接进 drop 或标志性 intro）。刹完接个平淡的 verse，戏剧性全浪费。
- **每个套路先"一对歌"练到稳定复现，再换歌验证。** 换了歌还能做出来，才是学会了套路；换歌就翻车，说明你背的是那两首歌的位置，不是技巧本身。

</div>

## 练习建议

每种套路按"固定一对歌练稳 → 换歌验证 → 录音回听"三步走。跨 BPM 三种解法各练 5 次，感受它们适合的场景差异。
