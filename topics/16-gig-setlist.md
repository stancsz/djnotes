# 职业级 Set 准备

第 14 课讲了一个 set 的内在结构（能量曲线、块状排歌），这一课讲职业维度：**同一套手艺，怎么按"场合"交付**。接商单后的第一个问题永远不是"我想放什么"，而是"这是什么场子、我在流程的哪个位置"。

## 60 / 30 / 10 法则

职业 DJ 歌单配比的经验公式：

- **60% 服务观众**：这个场子的人群明确想听的东西（问主办方、看场地过往活动、查同场 DJ 风格）
- **30% 你的标识**：你的风格印记——别人记住你、下次点名找你的原因
- **10% 冒险**：新歌、怪歌、实验性过渡。放对了是惊喜，放错了损失可控

新手常见死法是把比例倒过来：90% 放自己爱听的，观众不买账，没有下一场。

## 场合模板

| 场合 | 核心逻辑 |
|------|---------|
| 暖场 slot | 能量封顶七成，不放大歌（第 14 课讲过），服务 headliner |
| 婚礼/年会 | 曲目安全度最高，多代人都要照顾，主家歌单权限最大，报幕能力比混音重要 |
| 酒吧驻场 | 背景为主，能量随人流波动，一晚 3-4 小时——耐力和曲库深度的考验 |
| 俱乐部正场 | 你的 30% 标识可以放大，双 drop 等大招留在这里用 |
| 直播 | 互动节奏优先（第 12 课），版权安全歌单 |

## 冗余：职业和业余的分水岭

设备一定会出问题，职业的意思是出问题时观众听不出来：

1. **双载体**：笔记本 + 导出好的 U 盘（rekordbox 支持导出到 USB，虽然 FLX4 不读盘，但换到场地 CDJ 时救命）
2. **手机应急**：手机装 rekordbox app / 存一个 60 分钟应急 mix 音频——设备全灭时接调音台直推
3. **曲库三备份**：本机 + 移动硬盘 + 云（第 1 课的备份习惯在这里兑现）
4. 提前要到场地的**设备清单**（调音台型号、接口、监听），不要到场才发现没有 RCA 输入

<div class="protip" markdown="1">

- **为一场 60 分钟的演出准备 3 小时的歌。** 老师傅的 U 盘里永远是演出时长三倍以上的弹药——不是要全放，是为了任何方向的现场反应都有对应的下一步。计划歌单是地图，不是轨道（第 14 课的"块"在商单里同样适用）。
- **提前踩点一次，胜过十封邮件。** 演出前去一次现场（哪怕装作顾客）：听驻场音响的低频特性、看人群年龄和穿着、记下几点开始上人。这一小时的情报直接决定你 60% 那部分怎么配。
- **Opening set 是行业的信任考试。** 给 headliner 暖场时放了他风格的大歌，是圈内最快拉黑的方式。反过来，一个能把场子焐到"刚好差一口气"的暖场 DJ，会被 headliner 主动记住并推荐——暖场干得漂亮是新人最快的上升通道。
- **Back-to-back（B2B）的规矩**：每人 2-4 首轮换；不抢对方铺垫到一半的能量线；不在对方的歌上乱挂效果；结束后归还所有 EQ/Filter 到初始位。B2B 打得舒服的人，会被再次邀请——这本质是协作能力的展示。
- **每场演出录音，商单尤其要录。** 一是复盘素材，二是下一课（个人品牌）的内容原料，三是遇到"你上次放的那首是什么"的商机时能翻出来。手机压在台边录环境声都行。

</div>

## 实操作业

按"婚礼/朋友聚会"和"酒吧夜场"两个场合各排一套 60 分钟 set（用 60/30/10 法则），写清每套的能量曲线和三个应急预案。用第 15 课的 house party 实测其中一套。
