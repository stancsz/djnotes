# Networking 与行业潜规则

行业最大的公开秘密：**演出机会几乎全部通过人际推荐流转，冷投简历/私信的成功率接近零。** 订你的人要承担"这个 DJ 会不会砸我场子"的风险，推荐是唯一的风险担保。所以 networking 不是社交技巧，是职业基础设施。

## 机会的真实流向

```
场子缺人 → 主理人问驻场DJ"有没有靠谱的人" → 驻场DJ推荐你
```

注意链条里没有"投简历"环节。你要做的是让链条中间那个人**认识你、信任你、想起你**。

## 谁是"链条中间的人"

按优先级：

1. **同城其他 DJ**——不是竞争对手，是你最大的机会来源。DJ 时间冲突时会转单，生病会找替补，B2B 会带新人。
2. **酒吧/场地主理人和店长**——直接握有排期权。
3. **活动策划/派对主办**——办活动就需要 DJ。
4. **调音师/灯光师/摄影师**——他们跑所有的场子，消息最灵通。

## 怎么建立这些关系（不油腻版）

- **去现场，成为熟脸。** 同城的 DJ 活动持续出现，演出结束后真诚夸具体的某个过渡（内行的夸法自带身份识别）。三五次之后你自然进入圈子对话。
- **先给予，再索取。** 帮同行转发演出海报、给主办拍现场素材、直播时给同城场子导流——在开口要机会之前，先成为"有用的人"。
- **第 15 课的 house party 是社交武器**：办自己的局，邀请你想认识的 DJ 来玩（或 B2B）。请人来你的场子玩，比在别人的场子里递名片高效十倍。

## 行规红线（违反一次就出圈）

- **永远不公开说任何同行的坏话。** 圈子极小，话必传到。评价永远只说"风格不是我这挂的"。
- **准时是底线，提前是标准。** 演出迟到一次，主理人这辈子不会再订你。
- **答应的场子不放鸽子**，哪怕后来有更好的邀约。撕单的名声传播速度是光速。
- **不在别人的 set 时间蹭台**（除非被邀请），不动别人的设备设置。
- **喝酒上限两杯。** 台上烂醉的 DJ 只有一次机会。

- **免费演出的唯一正确算法：** 用"这场换来什么"评估——素材？人脉？场地经验？固定客源的试演？有明确答案就接，没有就婉拒。**"帮个忙先免费打，以后有钱了给你"的场子，永远不会有"以后"**——免费打出来的价码就是你的价码。
- **谈钱的姿势**：新人最怕开价。公式：先打听同城同级 DJ 的行价（问熟的同行，大家愿意讲），报价压在行价的 8 折起步，每接满 5 单上调一次。**永远在确认演出前谈好数字和结算时间**，"打完再说"= 大概率被砍价或拖款。
- **要定金。** 商单（婚礼/年会/商业活动）收 30-50% 定金是行业标准，不是不信任——没定金的档期被放鸽子，你损失的是那晚本可以接的其它单。
- **每场演出后 48 小时内跟进。** 给主理人发一条"感谢+两张现场好图+期待下次"。90% 的 DJ 打完就消失，做跟进的 10% 拿走了绝大多数回头单。
- **维护一张"关系台账"**：认识的每个业内人 + 在哪认识 + 聊过什么 + 上次联系时间。三个月没互动的关键人物，找个由头（转发他的活动、评论他的内容）刷一次存在感。机会流向"最近想得起来的人"。

## 实操作业

1. 列出同城 10 个"链条中间人"（DJ/主理人/主办），本月认识其中 3 个（去现场、评论互动、直播连线都算）。
2. 打听清楚同城新人 DJ 的行价区间，写下你的报价和涨价路线。
3. 建立你的关系台账（表格即可），把已认识的人先录进去。
