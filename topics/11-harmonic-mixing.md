# 调性混音（Camelot Wheel）

## 为什么要懂

两首调性冲突的歌叠在一起，即使 BPM 和节拍完全对齐，听感也"很怪"——耳朵本能察觉不和谐。调性混音用乐理关系挑出"天生该在一起"的歌，是从"能对上拍"到"选歌有品位"的关键一步。

## Camelot Wheel 基础

- 数字 1-12 = 五度圈位置，字母 A=小调、B=大调。
- 安全的过渡关系：
  - **完全相同**（8A → 8A）
  - **相邻数字**（8A → 9A 或 7A）
  - **同数字换字母**（8A → 8B，同主音大小调互换）

- **Energy Boost：+2 是藏在轮盘里的"升档键"。** 跳两格（8A → 10A）等于整体升一个全音，能量瞬间抬升，副歌感扑面而来。适合 set 需要"往上顶一层"的时刻。反向 -2 则是降温收场的暗招。规则内的 ±1/同号是"安全"，+2 是"起飞"——记住这个手感差别。
- **大小调的情绪语法：** A（小调）暗、深、drive；B（大调）亮、开、euphoric。8A → 8B 这类切换是整晚情绪的转折点：从 underground 的沉浸感切向 hands-up 的开阔感。排 set 时想的不是"下一首什么调"，而是"下一首什么情绪"，调性只是实现工具。
- **软件的 Key 检测大约一成是错的。** 转调的歌、人声主导的歌、和声复杂的老 funk/disco 最容易被标错。乐理是你的优势区：预听时自己哼主音核对。**耳朵永远是终审，轮盘只是初筛。**
- **短切几乎无所谓调，长叠必须讲调。** 调性冲突只在两首歌的旋律/人声长时间共存时刺耳。Echo 切、快切场景下 key 基本可以无视；32 小节的长层叠、还带人声的，key 不合直接翻车。花功夫的地方要花对。
- **别被轮盘锁死歌单。** 只按相邻 key 排歌，一晚上可能被困在两三个调里出不来，选曲越走越窄。老师傅的做法：能量优先，key 用来在候选歌里做最后筛选——它是过滤器，不是路线图。

## 实操练习

1. 挑 3 首 Camelot 相邻的歌混在一起，对比随机三首的听感差异。
2. 反向实验：故意混两首差 5-6 格的歌，把"不和谐"听清楚，给耳朵建标签。
3. 找一次 +2 energy boost 的机会（如 5A → 7A），感受能量抬升。
4. 抽查曲库 10 首歌的 Key 标注，亲耳核对，看错误率有多少。
