# 开箱与设置

## 目标

从箱子到能出声，走完一次完整的软硬件连接。这一课结束时，你应该能独立完成"插线—开软件—放歌—戴耳机监听"整套流程。

## 准备什么

- DDJ-FLX4 主机 + USB-C 数据线
- 一副耳机（建议封闭式监听耳机，隔音好，方便预听）
- 电脑装好 rekordbox（免费版即可解锁 FLX4 全部硬件功能，不需要付费订阅）

## 操作步骤

1. **接线**：USB 连接电脑，FLX4 免驱动，插上即被系统识别为一张独立声卡。
2. **打开 rekordbox**，进入 Performance 模式。
3. **Preferences → Audio**，确认 Audio Device 选的是 DDJ-FLX4，不是电脑自带声卡。
4. **耳机**插在前面板的耳机口（6.3mm 或 3.5mm 均支持）。
5. **导入曲库**：File → Import，或直接把歌曲文件拖进 rekordbox。首次使用建议把曲库全部跑一遍 **Analyze**，这样每首歌的 BPM、Key、Beat Grid 才会被计算出来，后面几课全部依赖这一步。
6. **走线**：家用练习可以只用耳机+电脑喇叭；如果要外接音箱，Master Out（RCA）接功放或有源音箱。
7. **通电检查**：Deck 1 装一首歌，按 PLAY，打开耳机 CUE 监听，确认声音正常。

## 常见坑

- Beat Grid 没对齐会导致后面 BPM/Sync 显示不准——先让 rekordbox 自动分析，明显跑偏的歌手动修一下 downbeat。
- Windows 上没声音，先检查系统输出设备有没有被切到 FLX4，但音量刚好开在没插耳机的那一路。

## 练习作业

导入至少 20 首歌并全部分析完成。独立完成一次"插线—开软件—放歌—戴耳机监听"全流程，不看教程。
