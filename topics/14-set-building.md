# 读场、排歌与登台

前 13 课练的是"怎么混"，这一课讲"混什么、什么时候混"——技术之外真正区分 DJ 高下的东西。混音技术三个月能练到能用，读场和排歌是一辈子的功课。

## 能量曲线：set 的骨架

一个 set 不是歌的列表，是一条设计过的能量曲线。基本形态：

```
能量
 ▲                    ┌─ 高潮段 ─┐
 │              ┌─────┘          └──┐
 │        ┌─────┘                   └───┐
 │  ┌─────┘  （中途留呼吸口）           └──
 └──┴────────────────────────────────────▶ 时间
   开场            中段              收尾
```

- **开场**：低调进入，铺氛围，别把最好的牌先打掉。
- **爬升**：每 3-4 首歌上一个能量台阶，中途故意放一首"呼吸歌"让场子歇口气——一直顶着最高能量，30 分钟后观众就麻了。
- **高潮**：把硬货集中在场子最热的窗口。
- **收尾**：有意识地降落，而不是戛然而止。

## 排歌方法：块，不是链

新手排歌爱排"一条链"：第 1 首接第 2 首接第 3 首……现场一有变化整条链就崩。老师傅排的是"块"：

1. 把候选歌按能量档位分成 3-5 个块（暖场块、爬升块、炸场块、呼吸块、收尾块）。
2. 块内的歌 BPM 相近、调性兼容、任意两首都预演过能接。
3. 现场按观众反应决定"下一块去哪"，块内自由选歌。

计划的是路线图，不是轨道。

## 读场：看什么

- **看脚不看手。** 举手拍照可能是礼貌，脚在动才是真的在跳。脚步停了，就是能量掉了的信号。
- **看场子的"中间层"。** 最前排永远热情、最后排永远冷淡，都不可信；中间那批人跟不跟，才是场子的真实温度。
- **一首歌给两个乐句的机会。** 反应不好别立刻慌着换——有时候是歌还没到 drop。但两个乐句过去还是冷的，果断走人，别和一首歌较劲。

- **暖场 DJ 的职业道德：不抢主角的活。** 如果你在别人前面打暖场，纪律是：能量只铺到七成、不放当晚 headliner 风格的大歌、不放当红炸曲。把场子"焐热但留着饿"，是暖场位最被行业尊重的手艺——也是新人最容易接到的活，干漂亮了机会自然来。
- **"救场三板斧"提前备好。** 场子突然冷掉时不是现想对策：① 一首"必杀安全歌"（你的场子里谁都买账的那种）；② Beat Jump 提前进入当前歌的 drop；③ 砍掉计划中的过渡曲直接跳到下一个能量块。三板斧都在 30 秒内可执行——慌乱的本质是没有预案。
- **记住"场子的歌"，建自己的数据库。** 每次演出/直播后花十分钟复盘：哪首歌让场子起来了、哪首放空了、什么时间段观众是什么状态。三五场之后你会有一份任何教程都给不了的私人情报——你的场子、你的观众的真实口味。
- **第一首歌定调，最后一首歌定记忆。** 观众对 set 的印象大头来自开头 5 分钟和结尾 5 分钟（峰终定律在舞池同样成立）。这两个位置的歌值得花双倍时间挑。
- **紧张是设备检查没做完。** 登台/开播紧张的真正解药是流程化 soundcheck：曲库导出到 U 盘/确认电脑电源、耳机线、Master 电平、Booth 电平、麦克风、第一首歌 cue 好。清单跑完，手就不抖了——你能控制的都控制了，剩下的交给练习量。

## 实操练习

1. 用现有曲库排出三个"块"（暖场/爬升/炸场），每块 5-8 首，块内任意两首预演互接。
2. 设计一条 45 分钟的能量曲线（画出来），按曲线打一次完整 set 并录音。
3. 回听录音，标出三处"如果在现场，观众可能掉"的位置，写出对策。
4. 直播实战：按能量块打一场，直播间人数/互动就是你的"舞池脚步"——练读场。
