# DJ Notes: DDJ-FLX4 从开箱到能上场

[打开课程网站](https://stancsz.github.io/djnotes/) · [从第一课开始](https://stancsz.github.io/djnotes/topics/01-setup/) · [查看视频资源清单](https://stancsz.github.io/djnotes/notes/ddj-flx4-playlist/)

一套给中文初学者的 DDJ-FLX4 实战课程。它不只解释按钮是什么，也把学习路线连起来：装好 rekordbox、用耳朵对拍、做干净的过渡、准备一场 set，再到第一次接演出和经营自己。

**适合谁：** 已经拥有或准备购买 DDJ-FLX4，想用一条明确路径学习 DJ 的人。课程以 FLX4 + rekordbox 为主，但其中的听歌、乐句、选曲、准备 set 与现场思维也能迁移到其他 DJ 设备。

## 从这里开始

课程已发布为可直接阅读的网站，无需安装任何软件：

1. 从 [第 1 课：开箱与设置](https://stancsz.github.io/djnotes/topics/01-setup/) 开始，完成设备、音频和 rekordbox 的基础设置。
2. 依序练到 [第 5 课：手动对拍](https://stancsz.github.io/djnotes/topics/05-beatmatching/)，不要跳过耳机监听和乐句结构。
3. 进入过渡、loop、cue、效果与调性混音，把每一课的练习真正做完。
4. 用 [练习计划](https://stancsz.github.io/djnotes/topics/13-practice-plan/) 和 [视频资源清单](https://stancsz.github.io/djnotes/notes/ddj-flx4-playlist/) 形成自己的固定训练节奏。
5. 准备好第一次完整 set 后，再学习 house party、职业级备歌、品牌与接演出。

## 每一课有什么

每节课围绕一个真实动作展开，而不是堆术语：

- 先解释该动作在一场 mix 里的作用
- 再写清楚它在 DDJ-FLX4 和 rekordbox 上的操作位置
- 配合控制器示意图、练习作业与老师傅经验
- 在适用时附上可继续学习的 YouTube 教学视频

课程网站也提供一份 [DDJ-FLX4 学习视频清单](https://stancsz.github.io/djnotes/notes/ddj-flx4-playlist/)。它按入门、操作、听力与过渡的顺序整理，方便把课程练习和视频演示搭配使用。

## 本地预览与贡献

这是一个 Jekyll 静态网站。若要在本地编辑并预览，需要 Docker 和 Bash（Git Bash、WSL 或 macOS/Linux 终端均可）：

```bash
bash scripts/preview-jekyll.sh
```

然后打开 `http://localhost:4000`。脚本会启动 Jekyll 容器，停止预览进程后会清理对应容器。

内容修正、设备实践经验和更清楚的图示都欢迎通过 [Issue](https://github.com/stancsz/djnotes/issues) 提出。提交前请确认：

- 经验性建议和可验证的设备/软件事实有明确区分
- 外部视频链接仍可访问，且标题和讲解内容相符
- 新内容能帮助读者完成一个具体动作，而不只是增加术语

## 资料与边界

- 课程围绕 DDJ-FLX4 与 rekordbox 编写，软件界面、功能和设备兼容性可能随版本变化。重要设置请以 [官方用户手册](https://stancsz.github.io/djnotes/assets/pioneer-dj-ddj-flx4-user-manual.pdf) 和当前官方说明为准。
- 链接或嵌入的 YouTube 视频由各自创作者拥有。本仓库不主张拥有这些外部内容。
- 课程中的职业建议来自经验整理，不保证获得演出、收入或任何特定结果。
